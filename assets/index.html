iiif.link

A link shortener for IIIF document views. Open any IIIF manifest, frame the exact page, zoom and pan you want, then mint a short permanent link that reopens that precise view.

How to use

  1. Paste a IIIF manifest URL and press View.
  2. Navigate: turn pages, zoom, pan, rotate, toggle layers.
  3. Press Create link — the field becomes your shareable URL, copied to the clipboard.
  4. Anyone opening the link lands on the same view.
